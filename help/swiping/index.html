Swiping

Slide a card or a line sideways and a button appears under it. Tap the button to do it; slide back or tap anywhere else to leave it.

WhereSlide rightSlide left
A task, on Home, Tasks, a list or a thing’s pageDone, todayRemove
A check-up — a task that repeats, like a filter every 3 monthsDone, today; the next one is setStop repeating — turn it back on under Check-ups
A line on a task’s checklistEditRemove
A room, person or animal while setting up—Remove

A task or check-up does the same from inside it: open it and use Mark it done or Delete. Removing a task keeps what was already done in the history.

On a computer there is no swipe: the Tab key reaches the same buttons, and they slide into view.
