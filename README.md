# DwelLogs.com

The public website for [DwelLogs](https://dwellogs.com) — everything your
home needs, before it needs it. Free, for owners, renters, condos, and ranches.

Plain static HTML served by GitHub Pages from `main`. No build step.

## Working on the site

- Open `index.html` in a browser to preview.
- Branch from the current release branch (`release/v0` pre-launch) as `<card#>-short-name`, PR back into it.
- `main` only changes when a release merges, and that's when the site updates.
